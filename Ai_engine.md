# Project Context: RecallScope

## Overview
**Project Name**: RecallScope
**Domain**: AI-Powered Discovery Engine for Vague-Memory Photo Retrieval
**Target Platform Context**: Google Photos
**Role**: Senior Full-Stack Engineer, Applied-AI/Data Engineer, and Product Designer.

**Core Goal**: Increase the percentage of users who successfully retrieve a photo they remember but cannot precisely describe when they start searching. This is an engine to research and evaluate this problem by analyzing real user evidence (reviews, forums), structured via an LLM pipeline, and presented in a rigorous, evidence-backed UI.

## 1. The Analytical Frame
- **Retrieval Funnel (F1-F6)**: Tracks where the retrieval experience breaks down (Start, Express, Understand, Recognize, Refine, Finish). F0 is out of scope (e.g., photo not backed up).
- **Memory Lens**: Analyzes how users remember (content, context, purpose, feeling, time, source) versus what they forget, testing the hypothesis of a vocabulary and format mismatch with current search engines.
- **Hypotheses / Archetypes (A1-A8)**: Configurable starting assumptions (e.g., fuzzy place memory, utility photos, received media, text-in-image) that the data will either support, reject, or expand upon via unsupervised clustering.

## 2. Data Collection Layer
- **Sources**: Google Play, App Store, Reddit, Google Photos Community, YouTube, Hacker News/Twitter (optional), and Manual CSV/JSON import.
- **Constraints**: Public content only, anonymized, no live scraping in the deployed public app (use a precomputed dataset snapshot), resumable and idempotent collection.
- **Target Scale**: 3,000–8,000 raw items yielding 800–2,000 relevant records.

## 3. LLM Analysis Pipeline
- **Stage A (Relevance Filter)**: Fast/cheap LLM (e.g., Haiku/Flash) to classify `retrieval_related` (yes/adjacent/no).
- **Stage B (Structured Extraction)**: Stronger LLM (e.g., Sonnet/Pro) to extract strictly validated JSON conforming to a provided schema.
  - *Strict Rule*: Evidence quotes must be verbatim substrings (max 25 words).
  - *Strict Rule*: Numbers and stats are computed in code, never generated by the LLM.
- **Stage C (Embeddings & Discovery)**: Embed cleaned text, reduce (UMAP), cluster (HDBSCAN), and use LLM to name novel clusters to find unexpected archetypes.

## 4. Analysis Modules
1. Funnel leak analysis
2. Remembered vs. forgotten clues
3. Query Lab (vocabulary mismatch)
4. Opportunity scoring (Frequency, Severity, Unresolved, AI Addressability, Strategic Fit)
5. Compare mode for segments/archetypes
6. Hypothesis Court (seek counter-evidence)
7. Trend and Ask Photos impact
8. Segment lens
9. Research gaps and interview kit auto-generation
10. Coverage and bias panel

## 5. UI/UX & Features
- **Design Principles**: Evidence-first (clickable numbers opening quotes), calm/analytical tone, honest about uncertainty/sample sizes, accessible (WCAG AA, color-blind safe).
- **Key Views**: Overview, Funnel Explorer, Memory Map, Opportunity Board, Discovery Map, Evidence Library, Method & Trust.
- **Conversational Evidence Layer ("Ask the Evidence")**: Grounded chat agent with tools (sql_query, semantic_search) to answer complex queries about the dataset with inline citations.
- **Live "Try It" Mode**: Allows a judge to paste text/URL to run the pipeline live and see the structured output.

## 6. Technical Architecture
- **Pipeline**: Python 3.11, pandas/DuckDB, Pydantic, umap-learn, hdbscan, scikit-learn.
- **App Stack**: Next.js (App Router), TypeScript, Tailwind CSS, shadcn/ui.
- **Visuals**: Recharts/visx/D3, UMAP on canvas/WebGL.
- **Data Storage**: Precomputed JSON/SQLite/Parquet (in-app vector search).
- **Hosting**: Free-tier public deploy (e.g., Vercel) with no login required.

## 8. Definition of Done
- Public URL without login, mobile-responsive, and performant.
- Minimum 3 sources, 800+ relevant records.
- Verbatim quotes mapping to funnel stages.
- All UI views and features (Funnel, Opportunity Board, Chat, Try It, etc.) functional.
- Quality metrics displayed (precision/recall/kappa).
- Clickable evidence everywhere, color-blind safe design.
- README, docs, workflow diagram export.
